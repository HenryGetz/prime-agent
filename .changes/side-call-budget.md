- `/refine`, the automatic refine review and branch summaries no longer cut off models that may reason: these calls now get the model's whole output budget (fitted to the context window), as the TypeScript version did with reasoning on. The 32,000 / 4,096 / 2,048 token caps now apply only when the call really runs without reasoning (a model without thinking, or a route that turns thinking off when no reasoning is sent), and never exceed the model's own output limit.
