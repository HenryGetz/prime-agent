- `/refine`, the automatic refine review and branch summaries no longer cut off models that reason: these side calls now ask for the same output budget as a normal turn (the model's limit, up to 32,000 tokens unless `maxTokens` is set explicitly), fitted to the context window. Before, the review asked for at most 4,096 tokens and branch summaries for 2,048, which a reasoning model could spend before its answer.
